The new cut contains a phrase-directed standard Tamil male reading (Valluvar),
measured pauses, synchronized captions, original music, and smooth dissolves.
The proxy and certificate connection issue was resolved with TLS verification
kept enabled. All 35 lines remain unchanged. The narration should be listened
to and refined as needed; it is a stock neural voice, not a celebrity imitation.

Visuals in these films are AI-generated stills with camera motion. Genuine
AI-generated moving footage remains pending a video-service account and an
agreed budget. The prompt JSON is a preparation file, not finished footage.

After these files have been uploaded to GitHub, open a file and use **Download
raw file** to save it. To download the entire repository, use **Code → Download
ZIP**. The project archive also contains instructions for adding a narration
recording you are authorized to use.
