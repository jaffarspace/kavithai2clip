# ஒரு வசந்தத்தின் வாசம்

Working title taken from the poem's final line. The original poem was supplied
by the user; all 35 lines and their punctuation are preserved.

- [Video: 100 seconds, portrait HD](oru-vasanthathin-vaasam.mp4)
- [Editable project: images, Tamil subtitles, and render helper](vasanthathin-vaasam-project.zip)

The film contains AI-generated seasonal tree imagery, Tamil captions, and
original ambient music. This first cut has no spoken narration because the
online Tamil voice service was unavailable in the cloud environment.

After these files have been uploaded to GitHub, open a file and use **Download
raw file** to save it. To download the entire repository, use **Code → Download
ZIP**. The project archive also contains instructions for adding a narration
recording you are authorized to use.
